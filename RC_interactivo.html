Relaciones del circuito RC serie

XC = 1 / (ωC),  ω = 2πf
Z = R + 1/(jωC) = R − j/(ωC)
|Z| = √(R2 + XC2) = √(R2 + (1/(ωC))2)
φ = arctan(XC / R)
|I| = Vin / |Z|,  VR = |I| · R,  VC = |I| · XC
Δt = (φ / 360°) · T,  T = 1/f
fc = 1 / (2πRC)
